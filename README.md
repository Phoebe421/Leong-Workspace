# Leong · 个人工作台

一个无需额外依赖的个人工作台：Overview、Career、To-do List 和每日情报。界面为中文，布局适配桌面与手机；本地 HTML 在手机系统文件预览中的交互支持取决于浏览器。

## GitHub Pages 网页发布

仓库根目录的 `index.html` 是完整的独立网页，包含个人规划初始模板，运行不需要 Python。上传到 GitHub 后，在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存后等待发布。首页时钟每秒更新，显示上海时间。任务和记录保存在每台设备的浏览器内，通过备份文件转移；Pages 本身不提供数据同步。当前 Pages 版本的新闻是来源入口，尚未接入自动新闻抓取。

**发布前注意：**首页模板包含用户要求的留学和职业规划内容；公开 Pages 页面上的这份初始模板可被访问者查看。浏览器里后来添加的任务和记录保存在本机，未上传到 GitHub。

`python3 tools/export_standalone.py` 更新独立 HTML 后，将 `exports/Leong-Workspace.html` 复制到根目录 `index.html`，再发布。

## 不运行服务也能打开

下载 `exports/Leong-Workspace.zip`，在电脑解压后，用 Chrome 或 Edge 打开 `Leong-Workspace.html`。本地版本无需安装软件或运行命令，数据保存在当前浏览器内，页面底部支持导出与导入 JSON 备份。已根据本次对话加入美国申博、台湾大学留学规划与经历、重修申请、雅思准备四条主线及 AI 技术基础、医学影像 AI 科研两个支撑目标，共 23 项建议待办。已确认 2026 年申请、2027 年入学、雅思目标 8.5；课程重修申请与台湾项目再次申请也已明确。具体截止日期、当前成绩和实际进度待补充。

本地版的每日情报仅提供资讯来源入口，实时读取需要下面的服务端版本和网络权限。微信或手机系统附件预览可能不运行网页脚本，请在电脑浏览器使用。执行 `python3 tools/export_standalone.py` 可重新生成本地版本。

## 启动

需要 Python 3.10 或更新版本，无需安装第三方软件包。

```sh
cd /workspace/Leong-Workspace
python3 server.py --host 0.0.0.0 --port 8000
```

浏览器通过运行环境提供的应用访问入口访问 8000 端口。默认命令 `python3 server.py` 只监听本机。此应用没有登录机制，适用于平台访问控制下的个人环境。

## 功能

- **Overview**：待办、已完成、职业目标、机会统计，近期重点、任务分布、基于目标起止日期的时间进度与资讯入口。
- **Career**：个人档案（工作经历、教育与研究、技能、志愿经历）、LinkedIn 与在线简历入口；目标、手动进度、日期、备注；关联阶段任务；记录机会及待了解、已申请、面试中、已获得、已结束状态。
- **To-do List**：创建、编辑、删除、完成、恢复任务；优先级、日期、分类、关联目标、搜索及状态筛选；Today、Week、Month 和未安排视图，依据目标日期，本周为周一至周日。
- **每日情报**：读取 TechCrunch AI、arXiv AI 和 BBC 经济 RSS，显示原文标题、摘要、来源、发布时间和链接。打开工作台自动读取，页面打开期间每 30 分钟检查更新，服务端缓存 30 分钟。每日内容随来源发布更新，并非邮件或关闭页面后的主动推送。来源多为英文，不生成或翻译新闻，不保证来源在当天发布。较早内容及源故障会明确标注。

资讯需要允许 HTTPS 域名 `techcrunch.com`、`rss.arxiv.org`、`feeds.bbci.co.uk`。网络配置生效后需重启服务或等待缓存到期。RSS 源无法访问时不会伪造资讯，会保留缓存内容并显示提示。

- **思考与灵感**：零碎想法与灵感分开存储，分别新增、编辑、删除、搜索，记录内容、标签和创建日期。

## 数据与验证

数据保存在 `.data/workspace.sqlite3`，资讯缓存保存在 `.data/news-cache.json`，均不提交到 Git。当前实例已加入用户要求的6 个规划目标和 23 项建议待办。新数据库默认空白；`tools/personalize.py` 是显式执行的一次性初始化工具，不会自动运行。通过 `WORKSPACE_DATA_DIR` 可指定存储目录；备份时先停服务，再备份完整数据目录。删除目标会解除任务关联，保留任务。当前是单人工作台，不包含跨设备云同步。

```sh
python3 -m unittest discover -s tests -v
node --check static/app.js
```

云任务已隔离，请使用现有 checkout，不要创建 Git worktree，除非用户明确要求。新任务需重新启动服务；不要依赖旧任务进程。
