# Leong Research · 科研工作台（第一期）

研究方向：AI＋普美显增强MRI／CT＋肝癌，最终研究目标待确认。

## 打开

下载 research.html 后在电脑浏览器打开即可。也可放在仓库根目录，在现有 GitHub Pages 站点的 /research.html 访问。Python 服务版本可从 /research.html 进入（文件同时放入 static/）。无需安装依赖或配置密钥。

## 已实现

- 课题总览：暂定题目、研究问题、阶段、截止日期、本周三件事、已明确方向；每次修改保留最多200个快照，随备份导出。
- 待确认问题与已确定决定分开记录，支持依据与确认人备注。
- 文献证据库：新增、编辑、删除、搜索与四类目标筛选；研究设计、结果、局限、借鉴点、DOI、Zotero链接、核对状态。
- 任务看板：优先级、截止日期、状态、协助人、资源需求、备注与文献关联；删除文献解除关联但保留任务。
- 浏览器本地保存、JSON导出与校验后导入；导入替换当前数据，先导出备份。
- 三个AI辅助按钮生成可复制的提问模板，未连接模型服务，不自动提取全文或生成实验结果。

## 下一阶段

数据准备、实验记录、论文写作仅提供明确标注的规划入口及准备任务，不计作已实现功能。尚未接入Zotero API、医院影像、跨设备同步或引用自动生成；UWE Harvard继续由Zotero负责。

## 数据边界

仓库只包含程序与研究方向模板，不包含患者记录和真实研究结果。新增内容保存在当前浏览器，不会通过页面上传GitHub；不同设备、浏览器、域名的数据互不共享。清除浏览器数据会丢失本机记录，定期导出备份。不要输入患者姓名、住院号或未经批准的医学数据。

## 验证

JavaScript语法检查；浏览器验证文献新增、刷新恢复、分类筛选、无效链接阻止、删除确认、任务表单和AI模板。备份校验单元检查见 research.test.cjs。
