# Leong Research · 我的科研城

下载 research.html，在电脑浏览器打开即可使用。GitHub Pages 开启后，站点 /research.html 为入口；现有 Python 工作台服务同样可访问 /research.html。

## 这次更新

- 粉色界面、深梅色文字、原创兔子与狐狸SVG贴纸、响应式五页导航；减少动效设置下关闭动画。
- 课题与决策：七阶段路线；每步记录所需资料、要做的决定、交付成果和并行写作；支持候选问题与选择原因、课题历史快照。
- 文献证据：先摘要筛选再精读；四类研究目标分开；记录纳排标准、影像与标签、标注、方法、划分、验证、比较、结果、局限与研究空缺；DOI / Zotero 返回原文。
- 数据准备：资源清单、批次筛选与标注汇总、排除原因、数据字典、质量问题。只存批准的汇总，原始影像与身份信息放在批准环境。
- 实验与结果：数据版本、患者划分、模型参数、代码版本、模型与逐例预测文件位置、完整运行记录；分析记录关联实验，保存指标、不确定性、校准、比较、误判、结论、图表与分析代码位置。
- 论文与任务：Introduction、Methods、Results、Discussion、Abstract草稿；关联文献、实验与其他来源；导师原意见与修改状态；任务关联阶段、协助人、需求、截止日期。

当前主要目标是先写两个候选问题、向老师确认数据、整理方法对照表。初始候选问题标为讨论示例；没有真实病例数或实验结果。选择候选问题时同步到当前研究问题，并保存修改前的课题快照。

## 保存与迁移

使用原本的浏览器保存位置（leong-research-v1），新版数据格式为2。打开时兼容迁移第1版记录，不清空文献、任务或决定。导入兼容第1版/第2版，校验后询问是否替换；换设备、域名或浏览器前导出JSON备份。清除浏览器数据会丢失记录。课题历史包含在备份中。

删除文献会解除任务、实验、草稿关联但保留记录；删除实验会解除分析和草稿关联。不直接上传患者资料或同步到GitHub。静态页面没有账户与跨设备同步。

## 能力范围

这是记录、关联和追溯工作台，不运行模型、不计算统计指标、不访问医院数据库。文件位置由用户填写。三个AI按钮只生成提问模板，尚未连接AI服务；结果草稿模板仅整理已录入记录且标注待核对。Zotero继续管理全文和UWE Harvard引用，工作台不替代其功能。
